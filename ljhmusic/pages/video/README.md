# 视频页面 - MV功能说明

## 功能概述
视频页面现已接入相关MV功能，MV的id来源于每日推荐的歌曲。

## 主要功能

### 1. 获取每日推荐歌曲
- 调用接口：`/new/songs`
- 获取最新的推荐歌曲列表

### 2. 获取相关MV
- 调用接口：`/song/mv?id=歌曲id`
- 从每日推荐的歌曲中提取id
- 为每首歌曲获取相关的MV列表
- 自动去重，避免重复的MV

### 3. MV播放
- 点击MV卡片后，调用 `/mv/url?id=mv_vid` 获取播放链接
- 在video组件中播放MV
- 支持播放进度记录

### 4. 下拉刷新
- 支持下拉刷新重新获取推荐歌曲和MV

### 5. 上拉加载更多
- 支持上拉加载更多MV内容
- 每次加载10首歌曲的相关MV

## 数据结构

### MV数据结构
```javascript
{
  vid: "MV的vid",
  name: "MV名称",
  cover_pic: "封面图片URL",
  duration: 时长（秒）,
  singers: [
    { name: "歌手名" }
  ],
  playcnt: 播放次数,
  sourceSong: {
    name: "来源歌曲名",
    singer: "歌手名"
  }
}
```

## 使用说明

1. 确保后端服务已启动（QQMusicApi）
2. 进入视频页面，自动加载每日推荐的相关MV
3. 点击MV卡片即可播放
4. 下拉刷新获取最新内容
5. 上拉加载更多MV

## 接口依赖

- `/new/songs` - 获取每日推荐歌曲
- `/song/mv?id=xxx` - 获取歌曲相关MV
- `/mv/url?id=xxx` - 获取MV播放链接

## 注意事项

- MV的可用性取决于QQ音乐的数据
- 部分歌曲可能没有相关MV
- 播放链接具有时效性
